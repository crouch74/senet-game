# Royal Game of Ur Motif Mapping

| Previous motif | Final motif | Notes |
| --- | --- | --- |
| `dot-cluster` | `star-cluster` | Fully replaces the weak dots-and-arc style with a richer inlaid shell/lapis star cluster. |
| `eye` | `eye` | Rebuilt as a heavy shell inlay eye with lapis pupil and carnelian accent, not a line icon. |
| `lozenges` | `checker-lattice` | Upgraded into a denser Mesopotamian diamond lattice with alternating shell and lapis inserts. |
| `ring-dots` | `stepped-chevron` | Replaced by stepped geometry to keep the set more architectural and historically plausible. |
| `rosette` | `rosette` | Preserved as the hero motif and rebuilt with shell petals, lapis dot inlay, and a carnelian core. |
